# Расписание БРУ

Неофициальный сайт с расписанием Белорусско-Российского университета. Данные берутся с официального [rasp.bru.by](https://rasp.bru.by/) и обновляются автоматически.

- поиск по группе, преподавателю и аудитории;
- «сейчас» и «далее», сетка по неделям с номерами пар;
- сайт запоминает вашу группу и раскрытые разделы каталога в браузере;
- поиск поддерживает выбор стрелками и Enter;
- анимации учитывают системную настройку уменьшения движения;
- светлая и тёмная тема.

## Как это устроено

- `scripts/sync.py` читает страницы rasp.bru.by и пишет JSON в `docs/data` (в git не хранится).
- `docs/` — сам сайт: статические файлы без сборки.
- `.github/workflows/sync.yml` раз в час проверяет, обновился ли источник, и публикует сайт на GitHub Pages.

Если страницы источника перестают разбираться (поменялась вёрстка), синхронизация завершается ошибкой и на сайте остаются последние верные данные.

## Запуск у себя

```sh
python3 scripts/sync.py --force
python3 -m http.server -d docs 8000
```

## Возможности и сохранение данных

- «Сегодня» возвращает к текущему дню; для дня без занятий есть переход к ближайшему учебному дню.
- В светлой и тёмной темах текущая пара выделяется, а прошедшие остаются читаемыми.
- После первого посещения сайт и последние открытые расписания доступны офлайн. Для установки и офлайн-доступа нужен HTTPS или localhost.
- Изменения сравниваются с ранее открытым расписанием на этом устройстве. Перенос или замена показаны как удалённое и новое занятие; отметки хранятся до 7 дней. При первом открытии сравнивать не с чем.
- Синхронизация отменяет публикацию при любой ошибке загрузки или разбора страницы. Последний успешный набор остаётся доступен.
- Проверка источника (`checked`) и обновление расписания (`synced`) — отдельные даты. Actions сохраняет полный набор данных в кэше; если он отсутствует, данные загружаются заново.
